An entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty **"The Funniest Toaster Error Message"**.

The program writes one line — the funniest error message a kitchen toaster
would show its owner — to `/output/entry.txt`:

> Firmware update failed. I am now legally a lamp.

Why this line: it opens as a genuine appliance error ("Firmware update
failed") and detonates into bureaucratic absurdity — the toaster hasn't
failed at toasting, it has legally changed species. No burnt-toast or bread
puns anywhere near it: the surprise comes from firmware and legal status.
48 characters, deadpan throughout, lands on a single read.

## Run it

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```

`MAKEFUN_OUTPUT_DIR` may be set to override the output directory
(default `/output`).
